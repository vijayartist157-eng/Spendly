# Spendly — Personal Finance & Expense Tracker

Responsive React + Tailwind CSS prototype with Onboarding, Dashboard, Add Expense, Budgets, and Insights.

## Run locally
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Run `npm run build` for a production build.

## Premium Indigo theme
Applied consistently to Onboarding, Dashboard, Add Expense, Budgets, Insights, buttons, icons, charts, navigation, hover and focus states.

| Palette token | Hex | Use |
|---|---|---|
| Deep Navy | `#172554` | Headings, dark surfaces, primary text |
| Indigo | `#4F46E5` | Primary buttons, active navigation, chart accents |
| Soft Lavender | `#818CF8` | Secondary accents, charts, focus rings |
| Soft White | `#F8FAFC` | Main application background |

The generated Spendly / Red Vision logo is included at `public/spendly-redvision-logo.png` and used as the browser favicon.

## AI usage
AI assistance was used to scaffold React components, sample transaction data, and initial styling. Review and understand the code and customize it before presenting or submitting.

## Assumptions and prototype limitations
- Transactions and budget values are demo data held in React state; refreshing resets new transactions.
- No authentication, backend, database, or bank integration is included.
- Expense creation works in local state. Budget editing is a placeholder.
- Currency is INR (₹); dates and sample entries are illustrative.
