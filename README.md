# Spendly - Expense Tracker Application

This is a frontend web application built using React and Vite, designed to help users track and manage their financial transactions effectively.

## 🛠️ Tech Stack
- **Frontend Framework:** React (Vite)
- **Styling:** CSS (src/style.css)
- **Language:** JavaScript / JSX
- **Package Manager:** npm

## 🚀 Setup and Installation Instructions

Follow these steps to run the project locally on your system:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vijayartist157-eng/Spendly.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd spendly-premium-indigo-updated
   ```
   *(Note: Change the directory name if your folder name is different)*

3. **Install the required dependencies:**
   ```bash
   npm install
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. **Open the application:**
   Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal).

## 💡 Assumptions Made
- The application currently relies on frontend state (or localStorage) to manage data, as a dedicated backend database connection was not explicitly requested or provided in the initial assets.
- Node.js (v18 or higher) is installed on the user's machine to run the npm commands.
